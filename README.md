第 0 章　开工前：先搞清楚你要养的是什么
=======================================

「龙虾」是开源项目 OpenClaw 的中文昵称（官方吉祥物就是一只龙虾 🦞）。它不是
一个聊天网页，而是一个装在你自己服务器上的 AI
管家：7×24 小时在线，能读写文件、
执行命令行、刷网页、定时巡检，并通过飞书、Telegram
等聊天软件接收你的指令。

> **关于「ClawdBot → Moltbot → OpenClaw」的改名史**：这是社区流传的说法，
> 官方文档并未记载这段叙述，只在遗留的 socket 软链（`clawdbot`、`clawdis`、
> `moltbot`）和旧字段 `metadata.clawdbot` 里能看到痕迹。说法本身不矛盾，
> 但你不必当真，知道它现在叫 OpenClaw 就够了。

> **关于「接入微信」**：微信渠道确实可用，但**不是内置功能**，需要额外安装
> 外部插件 `@tencent-weixin/openclaw-weixin`（腾讯微信团队维护），
> 且**仅支持单聊与媒体收发，不支持群聊**。飞书、Telegram 等才是内置渠道。
> 新手建议先跳过渠道配置，用网页控制台跑通全流程。

**三个关键认知，先记住能少走很多弯路：**

-   它自己不带脑子。龙虾只是「身体」，必须接一个大模型当「大脑」------这就是你要去申请的那把
    API Key。

-   它跑在服务器上，不是装在你电脑上。这样你关机、睡觉时它照样干活。

-   它拥有你服务器的真实操作权限。所以「安全」不是口号，第 7
    章的红线请务必照做。

整体流程一览：

1.  买一台云服务器（第 1 章）

2.  给 AI 办一张「身份证」------ 申请大模型 API Key 并充值（第 2 章）

3.  在服务器上安装龙虾（第 3 章）

4.  跑初始化向导，把大脑接上（第 4 章）

5.  验收：让它干第一件活（第 5 章）

6.  翻车了怎么办：常见问题与正确修正（第 6 章）

第 1 章　买云服务器：怎么选才不踩坑
===================================

1.1 配置怎么选
--------------

最核心的一条：内存不能低于 2GB，建议直接上 4GB。原因是龙虾（基于
Node.js）在启动和编译阶段比较吃内存，2GB
的机器不做处理很容易被系统「杀进程」，表现为服务莫名其妙消失------这是新手最高频的翻车点之一。

  **用途**   **CPU / 内存**   **系统盘**   **带宽**     **适合谁**
  ---------- ---------------- ------------ ------------ -----------------------------
  最低能跑   2 核 2GB         40GB SSD     3～4 Mbps    纯体验、愿意折腾
  推荐配置   2 核 4GB         60GB SSD     4～6 Mbps    绝大多数个人用户（首选）
  进阶       4 核 8GB         80GB+ SSD    8～10 Mbps   多 Agent 并行、长期重度使用

提示：买「轻量应用服务器」，不要买普通云服务器（ECS/CVM）。轻量服务器套餐固定、价格透明、自带流量包，对新手友好得多；普通云服务器配置项繁琐且容易额外计费。

1.2 厂商与价格（2026 年参考价，活动价随时变，以官网实时页面为准）
-----------------------------------------------------------------

  **厂商 / 套餐**          **配置**                **参考活动价**                  **说明**
  ------------------------ ----------------------- ------------------------------- --------------------------------
  腾讯云轻量               2 核 2GB                约 68～99 元/年                 新用户专区，常有限量秒杀
  腾讯云轻量               2 核 4GB                约 199 元/年（3 年约 528 元）   性价比高，推荐
  腾讯云 Agent 专区        4 核 4GB                约 100～110 元/年               预装 Agent 环境
  阿里云轻量               2 核 2GB                约 38 元/年秒杀、68 元/年常规   每日限时限量，需蹲点
  阿里云轻量               2 核 4GB                约 199 元/年                    常规优惠，容易买到
  阿里云「智能体专用型」   2 核 2GB + 2 亿 Token   约 262 元/月起                  算力与模型额度打包，省心但偏贵

**选购要点：**

-   认准「新用户专区 / 秒杀专区」，首年价格往往是续费价的几分之一。

-   看清续费规则。很多低价套餐仅限首年，续费恢复原价；标注「同价续费」的最省心。

-   地域选择：主要在国内用选北京 / 上海 /
    广州；如果需要顺畅调用海外模型或抓取境外网页，选中国香港 /
    新加坡（延迟低、无需备案流程）。

-   系统镜像：优先选 Ubuntu 22.04 或
    24.04（资料最多、出问题最好查）。部分厂商提供「OpenClaw
    应用镜像」，选它可以跳过第 3 章大部分步骤。

1.3 买完必做：放行端口
----------------------

这是新手第二大翻车点，也是**最容易酿成安全事故的一步**，请务必按本文做，
不要图省事。

**先说结论：18789 端口绝对不要对公网（0.0.0.0/0）放行。**

龙虾的控制台不是普通网页 —— 它拥有服务器的 **shell 权限**，能读写文件、
执行命令。一旦把它暴露在公网上，相当于把服务器的钥匙挂在大门外，
全网任何人都可以扫描到并尝试进入。官方文档明确写道
*「Avoid direct public port-forwarding to the Gateway」*，
并把「公网直连」列为**罕见且高风险**的用法。

**正确做法：让控制台只监听本机，再用 SSH 隧道连进去。**

第一步，让网关只绑定本机回环地址（安装后执行一次即可）：

openclaw config set gateway.bind "loopback"

openclaw gateway restart

第二步，在你自己的电脑上开一条 SSH 隧道（**在你本机执行，不是服务器上**）：

ssh -L 18789:127.0.0.1:18789 root@你的公网IP

保持这个窗口开着，然后在你本机浏览器访问：

http://127.0.0.1:18789

这样就等于「你的电脑」和「服务器」之间拉了一根加密专线，
外网完全看不到这个端口。

**三种访问方式怎么选：**

  **方式**                            **适合谁**           **安全度**
  ---------------------------------- -------------------- ------------
  SSH 隧道（上面这条）                绝大多数新手         ★★★★★
  Tailscale 等内网穿透组网            有多台设备要连       ★★★★★
  反向代理 + HTTPS + 身份鉴权        确需公网访问的进阶用户 ★★★☆☆

> 如果你确实必须让它在公网可访问，官方文档的要求是：前置**身份感知代理**
> （identity-aware proxy）+ **TLS**，而不是裸开端口。
> 这属于进阶配置，新手请一律走 SSH 隧道。

**云厂商安全组**：只需要确认 **22 端口**开放（SSH 远程登录，一般默认已开）即可。
服务器内部的防火墙同样只放行 22：

sudo ufw allow 22/tcp

sudo ufw enable

> **注意**：如果你看到过别的教程让你执行 `ufw allow 18789`，
> 那是过时且不安全的写法。**不要执行它。**

第 2 章　给龙虾办「大脑」：申请 API Key 并充值
==============================================

龙虾本身不会思考，必须接一个大模型。国内新手首选
DeepSeek------中文好、价格低、充值门槛小（十元起）、国内直连不需要特殊网络。

2.1 主推方案：DeepSeek 开放平台
-------------------------------

**第一步：注册并登录。**

浏览器打开 https://platform.deepseek.com
，用国内手机号验证码登录即可（无需信用卡，无需境外手机号）。

**第二步：完成实名认证。**

在「个人信息」里按提示完成实名。未实名无法创建 Key、无法调用
API------很多人卡在这一步却不知道原因。

**第三步：充值。**

左侧菜单点「充值」→ 选「在线充值」→ 金额选 10 元或 20 元起步（支付宝 /
微信都行）→ 完成支付。

注意：网页版和 App 聊天是免费的，充值余额只用于 API 调用。别充多了，先用
10 元试通。

**第四步：创建 API Key（最关键的一步）。**

左侧菜单「API keys」→「创建 API key」→ 起个名字（比如 openclaw）→ 确认。

红色警告：这串以 sk-
开头的密钥【只在创建时完整显示一次】，关掉弹窗就再也看不到了。请立刻复制到本地记事本或密码管理器保存。丢了只能删掉重建。

**第五步（可选）：验证 Key 是否可用。**

在服务器命令行执行（把 sk-xxx 换成你的真实 Key）：

curl https://api.deepseek.com/user/balance \\

-H \"Accept: application/json\" \\

-H \"Authorization: Bearer sk-你的密钥\"

返回账户余额信息即说明 Key 有效。

第 3 章　在服务器上安装龙虾
===========================

3.1 先登录服务器
----------------

Windows 用户：用系统自带的 PowerShell（或下载 Xshell、FinalShell
等工具），执行：

ssh root\@你的服务器公网IP

Mac / Linux 用户：打开「终端」，输入同样的命令。首次连接输入
yes，然后粘贴你在购买时设置的（或控制台重置的）root 密码。

输入密码时屏幕不会显示任何字符（连星号都没有），这是正常的，输完直接回车即可。

3.2 安装方式二选一
------------------

**方式 A：一键脚本（新手强烈推荐）**

curl -fsSL https://openclaw.ai/install.sh \| bash

脚本会自动检测系统、安装 Node.js 依赖并引导配置，等待 2～5 分钟。Windows
服务器则用 PowerShell（管理员身份）执行：

iwr -useb https://openclaw.ai/install.ps1 \| iex

**方式 B：npm 安装（适合已有 Node 环境）**

npm install -g openclaw\@latest

装完先验证，出现版本号即成功：

openclaw \--version

3.3 前置环境检查（重要）
------------------------

龙虾要求 Node.js 22 或更高版本。检查：

node \--version

如果版本低于 v22，或提示命令不存在，先装 / 升级 Node：

curl -fsSL https://deb.nodesource.com/setup\_22.x \| sudo -E bash -

sudo apt install -y nodejs git

3.4 强烈建议：给 2GB 内存的机器加 swap（防止莫名闪退）
------------------------------------------------------

如果你的服务器只有 2GB
内存，务必执行下面四行，否则龙虾可能在启动时被系统杀掉：

sudo fallocate -l 4G /swapfile

sudo chmod 600 /swapfile

sudo mkswap /swapfile

sudo swapon /swapfile

第 4 章　初始化：把大脑接上（onboard 向导）
===========================================

执行安装向导：

openclaw onboard \--install-daemon

\--install-daemon
参数会把龙虾注册为后台常驻服务，服务器重启后自动恢复运行------这是「7×24
小时在线」的关键，别漏掉。

向导会依次问你下面几项，照着选：

  **向导提问**                      **该怎么选**             **说明**
  --------------------------------- ------------------------ --------------------------------------------
  Continue?（是否继续）             Yes                      个人使用默认即可
  Setup mode（安装模式）            QuickStart               快速开始，其余项以后再调
  Model/auth provider（模型厂商）   DeepSeek                 第 2 章申请的那家
  Enter API key（填密钥）           粘贴 sk- 开头的密钥      粘贴后回车
  Default model（默认模型）         输入 deepseek/deepseek-v4-pro   也可用 deepseek/deepseek-v4-flash（更快更省）
  消息渠道（Channels）              Skip for now（先跳过）   新手先跳过，用网页控制台就够了

分步走完向导后，确认服务状态：

openclaw gateway status

看到 running 即表示网关已启动。然后打开控制台：

openclaw dashboard

命令会输出一个**一次性配对链接**（形如
`http://127.0.0.1:18789/#...` 的 browserUrl）。它是一个**短时效、一次性**
的链接，用于把你这台电脑与服务器配对；**不会**把长期有效的共享 token
暴露在链接里。

把它复制到浏览器打开，就进入了龙虾的图形界面。

> **旧教程会让你 `openclaw config get gateway.auth.token` 取一个 token
> 再拼进 URL 登录 —— 那套已经不是官方推荐的主路径了。**
> 现在走的是上面这种一次性配对链接，更安全也更省事。

如果你是按第 1.3 节把网关绑到了 loopback，那么**在你本机**先开好 SSH 隧道：

ssh -L 18789:127.0.0.1:18789 root@你的公网IP

再执行 `openclaw dashboard`，把输出的链接在本机浏览器打开即可。

第 5 章　验收：让它干第一件活
=============================

先跑一遍官方自检，它会告诉你有没有配置隐患：

openclaw doctor

然后在控制台对话里发一条最简单的指令，例如：

-   「列出当前目录下的文件」------ 能返回文件列表，说明文件读写正常。

-   「帮我在当前目录新建一个 test 文件夹」------
    执行成功，说明命令执行权限正常。

-   「帮我查一下今天北京的天气」------
    有联网能力时才会成功，可作为联网测试。

三条都能完成，恭喜你，龙虾已经养活了。接下来可以逐步：接入飞书 / Telegram
实现手机远程指挥（微信需另装外部插件
`@tencent-weixin/openclaw-weixin`，且仅支持单聊）；
安装技能插件扩展能力；设置定时任务让它每天自动干活。

第 6 章　翻车现场与正确修正（最重要的一章）
===========================================

下面按出现频率排序，每一条都按「症状 → 真正原因 →
正确做法」给出。照做基本能解决 90% 的问题。

6.1 控制台打不开、网页一直转圈
------------------------------

**症状：浏览器访问 http://IP:18789 无法连接。**

**原因：端口没放行，或网关根本没起来。**

**正确做法（按顺序排查）：**

7.  确认你是按第 1.3 节**走 SSH 隧道**访问的（浏览器应打开
    `http://127.0.0.1:18789`，而不是 `http://公网IP:18789`），
    且隧道窗口没关。

8.  在服务器上看端口是否被正常监听：lsof -i :18789

9.  重启网关：openclaw gateway restart，再看状态 openclaw gateway
    status。

10. 本地测试：curl http://127.0.0.1:18789 ，能返回 HTML
    说明服务本身是好的，问题在网络或浏览器（清缓存、换无痕窗口试试）。

6.2 提示 Node.js 版本过低
-------------------------

**症状：安装或启动时报版本错误。**

正确做法：node \--version 确认版本，必须 ≥ v22。低于 22 时重新执行第 3.3
节的 Node 安装命令，装完重开终端再验证。

6.3 服务莫名消失、进程自己没了
------------------------------

**症状：昨天还好好的，今天访问不了，日志也没报错。**

**原因：内存不足被系统 OOM 杀掉（2GB 机器高发）。**

**正确做法：**

11. 补做第 3.4 节的 swap 设置。

12. 检查资源：free -h && df -h（磁盘满也会导致崩溃）。

13. 仍不稳定就升配到 2 核 4GB------这钱比反复排查更值。

6.4 端口 18789 被占用
---------------------

**症状：启动时提示 port already in use。**

**正确做法：**

14. 查出占用者：lsof -i :18789，记下 PID。

15. 结束它：kill -9 进程ID。

16. 或者换端口启动：openclaw gateway \--port
    18790，同时记得去防火墙放行新端口。

6.5 API Key 无效 / 模型不回答
-----------------------------

**症状：报 401、Authentication failed，或完全无响应。**

**正确做法（逐条核对）：**

17. 确认 Key 完整复制------常见错误是开头漏了 sk- 或末尾带了空格。

18. 确认已实名认证（未实名即使有 Key 也调不通）。

19. 确认余额充足：返回 402 就是没钱了，去充值。

20. 确认模型名写对。DeepSeek 已退役 `deepseek-chat` 与
    `deepseek-reasoner` 这两个旧 ID，现在必须填
    `deepseek/deepseek-v4-pro` 或 `deepseek/deepseek-v4-flash`，
    填旧的会直接报 model not allowed。

21. 改完配置记得重启网关：openclaw gateway restart。

6.6 改了配置文件后启动不了
--------------------------

**症状：手改 openclaw.json 后网关拒绝启动。**

**原因：JSON 格式写错（多一个逗号、引号不配对），龙虾会做严格校验。**

**正确做法：不要硬猜哪里错，直接跑自动诊断与修复：**

openclaw doctor \--fix

它会指出具体哪个字段有问题，并自动迁移旧版配置项。修好后再重启。

6.7 权限报错 EACCES（Docker 部署常见）
--------------------------------------

**症状：报 Permission denied，多为挂载目录属主不对。**

**正确做法：修正宿主机目录属主（容器内用户通常是 UID 1000）：**

sudo chown -R 1000:1000 \~/.openclaw

6.8 通用万能排错顺序
--------------------

任何时候不知道哪坏了，按这个顺序来，别东一榔头西一棒子：

22. openclaw doctor ------ 自动体检，先看结论。

23. openclaw logs \--follow ------ 实时看日志，找第一条真正的错误。

24. free -h && df -h ------ 确认内存、磁盘没满。

25. openclaw gateway restart ------ 重启网关。

26. 仍不行就 openclaw doctor \--fix 自动修复配置。

第 7 章　安全红线（请务必照做）
===============================

龙虾拥有读写文件、执行命令行、访问浏览器的真实权限，它一旦被滥用，损失远大于「AI
说错一句话」。以下四条是底线：

7.1 API Key 当密码保管
----------------------

-   不要把 Key 提交到 Git 仓库、不要截图发群、不要写进前端代码。

-   推荐存为环境变量或用 \~/.openclaw/.env，而不是硬编码在配置里。

-   怀疑泄露就立刻删掉旧 Key、重建一个新的。

7.2 不要把控制台裸奔在公网
--------------------------

这一条是**全篇最重要的安全底线**，第 1.3 节已经给了具体做法，
这里再强调一遍原因：

-   **18789 端口绝不对公网（0.0.0.0/0）放行。** 控制台拥有 shell 权限，
    暴露公网 = 把服务器钥匙挂在大门外。官方口径与本文一致：
    避免对网关做公网直连。

-   **默认让网关只监听本机**：`openclaw config set gateway.bind "loopback"`，
    然后用 SSH 隧道访问。这是新手的最优解，零成本、零风险。

-   有多台设备要连，就上 Tailscale 这类内网穿透组网。

-   确需公网访问的进阶场景，必须前置**身份感知代理 + TLS**，
    不要自己裸开端口。

-   控制台链接用 `openclaw dashboard` 输出的**一次性配对链接**登录；
    不要把长期 token 拼进 URL，也不要把链接转发给别人。

7.3 权限从最小开始
------------------

-   先给只读权限跑几天，确认行为符合预期，再逐步放开写入和执行。

-   不要图省事直接给 root 全权限跑 Agent。

7.4 定期更新与体检
------------------

-   升级：openclaw update（或 npm install -g openclaw\@latest）。

-   体检：openclaw doctor 建议每周跑一次。

-   留意官方安全公告------这类 Agent
    框架迭代极快，安全修复往往随版本发布。
